# Phase A2.1 — 2D Registration Report

Status: **AWAITING HUMAN REVIEW** — gate before A2.2 (Blender reconstruction).
Generated by `scripts/register_photos.py` (OpenCV 5.0, headless).

## Method

1. HSV segmentation of green soldermask → board mask (filled + raw)
2. `minAreaRect` → perspective rectification to top-down (~20 px/mm)
3. Through-holes = voids in the raw mask enclosed by board fill,
   filtered by interior colour (wood-warm or dark interior) and
   circularity; edge notches = convexity defects > 1.5mm
4. Components = non-soldermask blobs, classified black / white / metal
   by tone, level A/B/C by area
5. Front/back registration: back holes mirrored in x and matched to
   front holes (nearest-neighbour, ≤6mm)

## Corrections this reveals vs. V3 build

1. **PCB-A is nearly square (≈104×100), not 104×88** — V3 outline too wide
2. **A has a large kidney-shaped slot right-of-centre** and a big left-top
   edge cutout — V3 only had notches + 2 round holes
3. **CLMP module is bigger (~40×48) and sits top-centre-right**
4. **Ceramic antenna is left-of-centre-bottom**, not lower-left corner
5. **Green shield zone is ~21×29 with a PRINTED white spiral pattern**
   plus a separate large mounted coil (~Ø20mm) at its bottom edge —
   V3 merged these into one small zone + small coil
6. A top edge has a white connector; mid-right has two "2R2" inductors

## Detector limitations (honest)

- Plated mounting holes inside board-edge lobes are only partially
  detected (edge-merged voids get classified as notches instead)
- On B, two black square ICs were misdetected as holes (marked 0.71/0.77
  in `overlay_b_front.png`); real holes = centre + corner/edge holes
- Level-C passives intentionally not enumerated — texture-level detail
- Scale is ASSUMED (A width=104mm from PART_019 envelope, B=62mm from
  relative size); confirm before A2.2
